Meltdown Test ×5

แบบบันทึกแนวกว้างสำหรับจอ notebook ทำ Meltdown Test พร้อมกันได้สูงสุด 5 Batch แต่ละ Batch มีนาฬิกา รายการชั่ง การสังเกต กราฟ และสรุปผลของตนเอง

รูปแบบใหม่ต่างจากเดิมอย่างไร

รายการที่ต้องกรอกอยู่ทางซ้าย และ Batch 1–5 เรียงเป็นคอลัมน์จากซ้ายไปขวา จึงกรอกข้อมูลของแต่ละ Batch ไล่ลงตามแถวได้โดยไม่ต้องสลับหน้า เครื่องมือยังคงการทดสอบ 2 ส่วนเดิมครบถ้วน: วัดอัตราการละลายด้วยการชั่งทุก 5 นาที และดูลักษณะเนื้อที่ละลายทุก 10 นาที

ไม่จำเป็นต้องทำครบ 5 Batch — เลือกใช้เพียง 1, 2, 3 หรือ 4 Batch ได้ตามงานจริง และเพิ่มจำนวน Batch ระหว่างทดสอบได้ทันที ข้อมูลในคอลัมน์เดิมจะไม่หาย
เมื่อทำมากกว่า 1 Batch ควรเริ่มแต่ละ Batch เหลื่อมกันประมาณ 1 นาที เช่น Batch 1 เริ่ม 10:00 น., Batch 2 เริ่ม 10:01 น. และ Batch 3 เริ่ม 10:02 น. เพื่อให้รอบชั่งทุก 5 นาทีไม่มาถึงพร้อมกัน ผู้ทดสอบจะมีเวลายกตะแกรง ชั่ง บันทึก วางตัวอย่างกลับ และเตรียมชั่ง Batch ถัดไป

เงื่อนไขที่ควรคุมให้เหมือนกัน

  • อุณหภูมิไอศกรีมเริ่มต้น แนะนำ −18 °C หรือใช้ค่าอื่นที่กำหนด แต่ต้องใช้ค่าเดิมทุก Batch
  • อุณหภูมิห้อง แนะนำ 25 °C และบันทึกค่าจริงทุก Batch
  • ตัวอย่างส่วนละประมาณ 80–100 g ระบบคิดผลเป็นเปอร์เซ็นต์เทียบกับน้ำหนักเริ่มต้นจริง
  • วางตัวอย่างทุก Batch ในบริเวณเดียวกันและพ้นทางลมแอร์หรือพัดลม
  • เตรียมถ้วยใส ตะแกรง จานแบน เครื่องชั่ง และเทอร์โมมิเตอร์ให้ครบตามจำนวน Batch ที่ทำพร้อมกัน

ขั้นตอนการใช้งาน

1
เลือกจำนวน Batch
กด 1–5 ที่แถบด้านบน คอลัมน์ที่ไม่ใช้จะซ่อนจากหน้าจอและเอกสารพิมพ์ แต่ข้อมูลยังเก็บไว้ หากเริ่มด้วย 3 Batch แล้วต้องการเพิ่มเป็น 5 ให้กดเลข 5 ได้เลย
2
กรอกข้อมูล Batch ไล่ลงตามแถว
ตั้งชื่อ Batch แล้วกรอกวันที่ ผลิตภัณฑ์ Lot ปริมาณการผลิต ผู้บันทึก อุณหภูมิห้อง และความชื้น แต่ละคอลัมน์บันทึกแยกจากกัน
3
เตรียมส่วนที่ 1 และเริ่มแต่ละ Batch ห่างกันประมาณ 1 นาที
กรอกน้ำหนักถ้วยเปล่า → ถ้วย+ตะแกรง → อุณหภูมิไอศกรีมเริ่มต้น → ถ้วย+ตะแกรง+ไอศกรีม ระบบคำนวณน้ำหนักตะแกรงและน้ำหนักไอศกรีมเริ่มต้นให้ แล้วกด ▶ เริ่มส่วนที่ 1 ของ Batch แรก จากนั้นรอประมาณ 1 นาทีจึงเริ่ม Batch ถัดไป ทำต่อไปตามลำดับ เพื่อให้มีเวลาชั่งและบันทึกแต่ละตัวอย่างก่อนรอบของ Batch ถัดไปมาถึง
4
บันทึกหยดแรก
ทันทีที่เห็นหยดแรกตกลงถ้วย กด 💧 บันทึกหยดแรก ในคอลัมน์ของ Batch นั้น ก่อนมีหยดแรก หากถึงรอบชั่งทุก 5 นาที ระบบจะถามเพื่อบันทึกน้ำหนักถ้วยเปล่าเป็นน้ำละลาย 0 g ตามเวลานัด
5
ชั่งทุก 5 นาที
เมื่อถึงเวลา ยกตะแกรงพร้อมไอศกรีมขึ้นโดยถือเหนือปากถ้วย ชั่ง ถ้วย+น้ำที่ละลาย เลือกนาที กรอกน้ำหนัก แล้วกด ✓ บันทึกน้ำหนักและเวลาจริง ระบบลบน้ำหนักถ้วย คิด % และพล็อตกราฟตามเวลาที่กดบันทึกจริง รายการล่าสุดอยู่บนสุด และแก้น้ำหนักหรือเวลาจริงได้ในรายการ
6
เตรียมและเริ่มส่วนที่ 2
ใช้อีก 1 สคูป วางบนจานแบน กรอกน้ำหนักจานรองและจาน+ไอศกรีม แล้วกด ▶ เริ่มส่วนที่ 2 ของ Batch นั้น ส่วนที่ 1 และส่วนที่ 2 รวมถึงแต่ละ Batch เริ่มไม่พร้อมกันได้
7
สังเกตทุก 10 นาที
ที่นาที 10, 20, 30, 40, 50 และ 60 เลือกผล: ละลายปกติ แยกเป็นน้ำใส เป็นฟอง จับตัวเป็นก้อน เป็นเกล็ดน้ำแข็ง หรืออื่น ๆ และเขียนรายละเอียดเพิ่มได้แต่ละช่วง
8
ครบ 60 นาที: จบหรือต่อเวลา
ส่วนที่ 1 สามารถกด ＋ ต่อถึง 120 นาที เพื่อเพิ่มรอบชั่งนาที 65–120 หรือกด ⏹ หยุดบันทึก และกลับมาบันทึกต่อภายหลังได้ ส่วนที่ 2 บันทึกถึงนาที 60
9
อ่านผลและเก็บข้อมูล
แต่ละคอลัมน์สรุปน้ำหนักตัวอย่าง เวลาหยดแรก % ละลายที่ 30/60/90/120 นาที ความผิดปกติ และกราฟของ Batch นั้น กด พิมพ์ / บันทึก PDF แนวนอน หรือดาวน์โหลด JSON เพื่อเก็บและนำกลับมาแก้ไขต่อ

สูตรและการตีความ

  • % การละลาย = (น้ำหนักน้ำที่ละลาย ÷ น้ำหนักไอศกรีมเริ่มต้น) × 100
  • เวลานัดใช้เตือนให้ชั่ง ส่วนกราฟใช้เวลาชั่งจริงที่บันทึกตอนกดปุ่ม
  • เวลาหยดแรกและชุด % การละลายตามเวลาใช้เป็น baseline เปรียบเทียบสูตรเมื่อเงื่อนไขทดสอบเหมือนกัน
  • ส่วนที่ 1 ใช้ดูแนวโน้มละลายเร็วหรือช้า ส่วนที่ 2 ใช้บันทึกตำหนิ เช่น แยกน้ำ เป็นฟอง เป็นก้อน หรือเป็นเกล็ด
  • เครื่องมือนี้ช่วยจับเวลา คำนวณ และบันทึก แต่ไม่ได้กำหนดเกณฑ์ผ่าน/ไม่ผ่านแทนเกณฑ์ของผลิตภัณฑ์

การบันทึกอัตโนมัติและข้อมูลเดิม

  • ข้อมูลทั้ง 5 Batch เก็บอัตโนมัติในเบราว์เซอร์เครื่องนี้ คอลัมน์ที่ซ่อนยังไม่ถูกลบ
  • ข้อมูลจาก Meltdown Test รุ่นเดิมจะย้ายมาใส่คอลัมน์แรก ๆ ได้สูงสุด 5 Batch โดยข้อมูลเดิมยังคงอยู่ในพื้นที่บันทึกเดิม
  • JSON ของหน้ารุ่นใหม่และข้อมูลรุ่นเดิมสามารถนำเข้าได้ ระบบจะใช้สูงสุด 5 Batch แรก
  • หากข้อมูลสำคัญ ควรดาวน์โหลด JSON และบันทึก PDF เก็บไว้อีกชุด
